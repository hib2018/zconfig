# 実機ファイル置換検証

最終更新: 2026-09-20

| OS | 状態 | 確認内容 |
|---|---|---|
| macOS arm64 | PASS | 同一ディレクトリ一時ファイル、flush、権限保持、原子的置換、復旧ファイル、古い元ファイル拒否、ディレクトリ／symlink 拒否 |
| Linux | 未実施 | CI 定義は存在するが、この作業環境での実機結果は未記録 |
| Windows | 未実施 | CI 定義は存在するが、ロック中ファイルを含む実機結果は未記録 |

macOS の確認は Zig 単体試験と、実際の `zconfig-core` を別プロセスで起動する Go 統合試験で実施した。Linux と Windows の欄は各ネイティブ CI または実機で同じ試験を実行した後にのみ PASS へ変更する。
